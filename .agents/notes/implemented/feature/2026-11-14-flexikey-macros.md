# Agent Note: FlexiKey映射、宏与恢复

Status: implemented

## 问题

自研应用尚无FlexiKey映射及宏。原厂托管Set2Driver忽略返回值，kb.dll部分包装返回的不是注册操作结果，键盘Ex还固定读取256项而托管数组只有255项。直接照抄会丢失错误并有越界；过滤器没有公开当前映射表getter，恢复也不能假设原来为空。

## 决定

- 以本机ControlCenter/Driver/HKFltrLib.h、x64/HKFltrLib.dll及Flexikey_Pack_6.27/Set2Driver、XmlRW、HookKeysTable为依据。核心契约拥有键盘扫描码、五种鼠标触发、按下/释放/延时、文本及系统事件；普通键与E077/E078前缀别名按原厂生成，不能当虚拟键码。
- 直接使用已有HKFltrLib的真实cdecl导出，逐项检查0成功及错误码、非空设备/集合句柄，释放集合与设备。不调用kb.dll不可靠的包装，不写自制驱动或SendInput替代路径。测试只注入函数指针和内存，不加载DLL或打开过滤器。
- 后续领域控制器从原厂C:/ComboKey/profile.xml的活动配置及page1[8/9]启用意图建立明确来源的恢复快照；原配置缺失/损坏不伪造空映射。自研配置、当前已应用意图和恢复记录分别拥有单一契约，写前绑定文件事实与能力，原厂控制者未释放时拒绝接管。
- 配置准备、逐设备替换、首错停止、原配置重放、原子记录与恢复重试组成事务；恢复报告配置/驱动接受状态，不宣称读回不存在的驱动映射getter。应用启动和录制均不自动写过滤器；录制只在用户明确进入期间订阅输入。
- 自研UI提供按键/鼠标选择、动作与序列编辑、延时、文本、程序启动、配置导入导出、预览确认、启停及恢复。系统事件仅匹配已成功应用的程序绑定，复用全局OEM事件入口；不记录宏文本或按键内容到日志。
- 键盘底层事件实现上移hal/key_events，逐键响应与宏录制复用同一实现及独立订阅生命周期；移除灯光私有Win32钩子实现。传递扫描码、按下/释放、注入标记及单调时刻，回调只入队；宏录制明确启停，灯光保持透传。停止信号不持有业务回调，避免生命周期环和已退出线程ID复用。
- 录制按原厂Class1/KeyboardHook默认Monopolize=false旁路观察，不吞掉键盘事件，避免漏掉录制前已按住修饰键的释放。源Class1对NumLock/右Shift排除E0标志、VK255补E0；Pause在本机驱动0x140008d6e..0x140008d93明确以E11D编码并补发45。共享解码采用该规范，原厂XML的E11D45复合值及旧录制E08A规范为E11D，界面事实相同规范化后去重；不向u16 SDK提交24位值或误录为NumLock。
- 宏录制过滤E077/E078触发前缀，不把它们当成可播放动作，也不因此终止录制；触发集合仍按原厂自动注册相应别名。该边界与逐键灯光接收Fn事件分开，不能在共享HAL中吞掉前缀。
- 多行文本使用全局Textarea原语，和Input共享field外观所有者；映射与宏界面归components/keymap及keymap.css。键名只从原厂HookKeysTable提取扫描码事实，不复制原厂界面。配置草稿、录制缓冲、保存意图和实际按键效果分开展示，录制忽略注入事件。
- 控制台使用左侧来源/设备/映射列表、右侧动作编辑、底部差异及统一确认恢复。配置文件使用version/name/configuration严格契约，必须包含键盘与鼠标完整配置；导入仅替换草稿，导出同样经过领域校验，均不写过滤器。原配置启用意图与page1标志不一致时明确预览标志变化，不静默同步。
- 本机HKKbdFltr.sys 2.1.0.6静态地址0x140008f03..0x140008f33及HKMouFltr的0x140008a41..0x140008a71确认类型3调用0x1400012a4，使用IoWriteErrorLogEntry写入0x40000000|u16事件号。程序启动消费System日志的过滤驱动来源，不伪造Arg001前缀。经典日志传输与严格记录解码上移hal/event_log，校准OutLog适配复用；记录号缺口/清空停止并报告，订阅只从当前尾部开始。
- 程序监听在过滤器写入后、最终记录提交前准备；仅Applied且内容完全匹配的已授权记录允许执行，Prepared时丢弃触发，读配置不启动。替换过滤器前停止旧监听；监听准备失败作为事务失败恢复前一配置和记录。监听每次执行核对已授权记录及原厂控制者，录制期间忽略触发；监听错误可显式重试，退出清理，不自动重放旧事件或执行导入草稿。

## 验证范围

纯逻辑和函数桩覆盖扫描码、Fn别名、UTF16、零终止、按键平衡、真实错误码、集合生命周期、任一注册部分失败及恢复；再覆盖文件变更、原子记录、旧预览和页面操作。通过构建和相关检查，不调用真实驱动、键盘钩子或程序启动。

## 影响与验证

核心11项、桌面keymap域28项、共享键盘3项、逐键回归19项、共享事件日志2项和校准回归40项检查通过；既有过滤库6项检查继续覆盖SDK函数桩边界。10项宏页面检查分批通过，连同除尘/性能选项20项组合检查通过；新增Pause及录制/布局4项复验通过。页面采用模拟IPC，不实际录制或启动程序。检查覆盖旧预览、原子保存、部分注册/标志/监听/提交失败补偿、损坏原文件后的恢复、能力丢失保留记录、录制离页与延迟完成清理、修饰键透传、Pause/NumLock编码、完整文本和程序路径预览及监听重试保留草稿。360/760/1440px回流和截图检查通过，差异从短胶囊改为当前/草稿左右卡片；长卡片截图使用足够高的独立视口，避免截图工具扩展视口后裁错工作区。

npm run build、cargo check --offline --workspace、control-sim编译及26项控件边界检查通过；Textarea复用Input外观并纳入多文件入口的原生结构与业务覆盖校验。移除灯光私有键盘钩子、校准私有日志传输以及宏预览的内容计数替代显示；保留其他领域接口。最新安装包尚未重新构建，完整性能档案仍待整合；后续授权映射热键与OSD见2026-11-14-oem-hotkeys-osd笔记，原厂进程检查已移交共享hal/oem_owner。

## 风险

原厂配置是保存意图，不是驱动映射回读；无法凭缺少配置证明过滤器为空。没有加载真实过滤库、安装键盘钩子、读取实际System日志或执行程序宏，实际输入、剪贴板服务和事件效果未验收。程序监听仅在本应用运行且用户已应用或显式启用时执行；硬件物理验收不阻止后续代码整合。

## 备选方案

- 直接复制Set2Driver的255项数组和忽略返回值：静态原生实现已证明存在边界及错误丢失，拒绝。
- 缺少原配置时清空过滤器当成恢复：丢失用户映射，拒绝。
- 用通用用户态注入取代原厂过滤驱动：功能和控制权语义不同，拒绝。
