# Agent Note: 配置界面去说明化

Status: implemented

## 问题

配置页面重复展示用途介绍、执行流程与恢复原理，控件和实际数值被说明段落分隔。用户明确要求以原厂界面的配置密度为参考，保持自研外观，以图形、数值和操作为主。

## 决定

扩展范围覆盖全部十个工作区及其当前可达子模块：控制台、散热、性能、显示、灯光、输入、电池、自动策略、档案、设置。显示模式、白光键盘和供电来源增加绑定现有事实/明确草稿的语义SVG；供电六条件改为紧凑图形规则卡，完整目标按需展开；USB/网络使用离散状态图标，不伪造比例或连接状态。设置图形卡删除用途介绍字段及消费者；档案只保留参数/绑定/实际执行结果。现有图形模块复用，不为已符合标准的监控另建装饰或重复数据源。

新增图形所有权先登记DESIGN.md；图形只接收现有类型化数据，不新增硬件读取。未知、未报告、过期、保存配置、执行后回读与目标草稿继续严格区分。所有页面需通过跨页草稿/确认/恢复与宽窄深浅截图检查，选取可选键盘/灯条/电池能力场景补充覆盖；不运行全量测试套件或真实硬件。

显示与白光读取失败撤销对应Profile及图形，读取错误和动作错误分开，成功读取清除读取错误且保留未提交草稿；白光开关与保留亮度分别绘制。热键范围预览保留完整已选动作名及规则，复用已有展开项，不以仅显示数量替代授权目标。档案执行明细默认折叠，具体失败步骤直接可见，统一错误入口拥有播报，避免重复alert。界面结构变化后的检查先展开明细，并在实际所属工作区验证；不削弱旧修订、补偿、未知或独立确认的断言。

继续使用现有灰白/蓝色令牌、语义SVG与Lucide，不复制原厂黑色霓虹皮肤。预设卡片只显示图形、名称和状态；性能开关与键盘功能采用紧凑分组；性能调节在宽屏并列。删除重复流程提示，原理说明归已有Collapsible，恢复目标采用紧凑事实列表。校准将实际接管影响保留为短事实，完整过程按需查看，不以隐藏风险换取简洁。

只调整展示层与文案，不改IPC、硬件能力判断、预览目标、确认、恢复、轮询或草稿所有权；错误及阻止执行的具体原因继续就地显示。不使用CSS批量隐藏说明或截断错误，不新增帮助系统和依赖。

## 影响与验证

十个工作区及条件模块完成统一：复用现有语义图形和实际IPC，补齐显示模式、白光/三区键盘、供电来源、除尘状态及SVG时段图。设置选项删除用途介绍字段及其渲染/样式，删除旧三区i元素和时间条span绘制；错误、实际变更与恢复入口保留。所有新增图形不建立读取、控制或持久状态所有者。

211项去重后的聚焦模拟IPC检查通过，涉及29个检查文件；不累计重复执行，不运行完整测试套件。80张截图覆盖十页×360/1440宽×深浅主题×顶部/底部，额外验证逐键/多区/独立灯条、USB/LAN/PD、节能与校准、供电六条件、档案与自启。覆盖图形随IPC更新、未知值、关灯保留档位、读失败撤销图形和执行快照、草稿保留、确认失效、失败补偿与恢复。读取错误独立清除，失败步骤可见且不重复播报。实际检查了散热、显示、灯光、输入、电池、自动策略、档案和设置的代表截图。

前端构建、边界、图标一致性、workspace cargo check、83篇笔记及本轮源码500/80行限制通过。Windows安装包已重新编译与封装，1028份构建输入前后摘要一致；包内前端、AMD64主程序、NSIS类型标记及五份外壳资源校验通过，测试夹具未进入产物。证据归target/ui-check/all-pages-ui-evidence.json及all-pages-package-verification.log；安装包摘要归安装包旁verification.json。没有安装或运行主程序，没有访问原厂接口、系统控制或硬件。既有原厂功能代码缺口与真机未验收状态不因本次UI改动而改变。

## 备选方案

拒绝仅缩小字体、隐藏所有caption、删除预览恢复以及将原理介绍改成另一组常驻提示。
