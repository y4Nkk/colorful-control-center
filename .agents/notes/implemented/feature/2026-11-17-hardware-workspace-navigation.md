# Agent Note: 硬件模块分类与侧边栏导航

Status: implemented

## 问题

用户将原12项目标补充为：控制台内模块分类并接入侧边栏独立界面，不再堆在控制台。原ControlWorkspace同时挂载监控和全部设备编辑器，导航只有控制台、档案、设置；热键只能滚动到控制台锚点。

## 决定

2026-11-20 侧栏「概览」与「性能与散热」是独立工作区。性能与散热把预设、风扇设置与除尘、性能选项和 CPU／GPU 控件放在同一页，预设芯片直接嵌入卡片中央。「电源与档案」按电源设置、配置档案分区，配置档案与既有规则可相互导航。托盘风扇入口直接进入性能与散热并定位风扇设置，托盘档案进入电源下的配置档案。旧的档案访问记录归一到新地址，已打开的编辑器仍按工作区或区域保活。

### 2026-11-19 性能档案并入系统

性能档案是系统页第四个区域，顺序为概览、风扇散热、性能调校、性能档案。复用现有分段控件与档案管理界面，窄窗口把标签排成两列。移除侧栏档案入口。切换标签保留档案草稿和选中档案，当前区域拥有可提交的预览。托盘预览直接打开第四个标签并选中指定档案。最近访问记录中的旧档案页标识一次转换为系统的档案标签，沿用同一存储键。档案标签保有独立的会话滚动位置。

### 2026-11-19 合并电源工作区

电池与节能、自动策略归入侧栏的「电源」，由 `PowerWorkspace` 一次挂载。电池节能、校准、原厂供电模式、平台电源、USB 和网络策略同页可达。各模块沿用现有草稿、读数和提交规则，共用工作区的预览与恢复入口。读取最近访问页时，旧的两个页面标识一次归一为 `power`。

电源页遵循 Apple Human Interface Guidelines 的阅读顺序、设置行对齐和分组规则。电池图、电量与供电状态在同一个摘要行内，系统报告剩余时间时才展示估算。开启充电范围限制时，开始及停止阈值在开关下方展开。档案应用共用一个分组，启动档案、供电与唤醒开关以及三条触发规则沿同一设置行对齐线排列。档案在关闭自动应用时仍可编排，确认记录与恢复沿用各自的事务范围。

### 2026-11-19 键盘与灯光合页

主导航以键盘图标和「键盘与灯光」进入 `KeyboardWorkspace`。键盘灯光占整行，按键映射和原厂热键在下一行等宽排列，窄窗口逐项纵排。灯光策略和外围灯区占整行。各模块共用页面预览入口，按所选范围应用或恢复。

原厂键盘灯请求进入「键盘与灯光」，在编辑弹窗关闭后聚焦键盘灯光区域并确认。启动读取将原灯光页和按键页的最近访问记录归一为 `keyboard`，导航只注册 `keyboard`。

### 2026-11-18 原厂布局整合

本轮把概览、散热和性能调校接回同一个系统工作区。系统内保留三块操作区和当前区域的预览入口，按需挂载并保留已编辑的草稿。预设模式和实时转速的当前归属见配置界面去说明化笔记的 2026-11-19 决定。设备配置集中屏幕、自动刷新、显卡及设备开关，按键映射与热键策略保留同一输入工作区。电池、灯光、自动策略、档案与软件设置按现有职责挂载。参照本机原厂 CC40 的系统与配置分区，沿用自研组件、色板和窗口。按区域暂停非活动编辑器及其可提交项，沿用现有预览、确认、恢复、热键定位与本地最近页面有效性检查。

### 2026-11-17 拆分决定

- navigation.ts拥有页面标识、中文标题、语义图标与分组；控制台只展示监控。风扇散热、性能调校、显示与显卡、灯光效果、键盘与输入、电池与节能、自动策略各自拥有Workspace。档案与软件设置继续独立，不复制已有领域编辑器。
- AppWorkspace唯一拥有访问记录与keep-alive挂载。页面隐藏后保留草稿/滚动和确认流程，active停止不必要订阅；硬件历史与跨模块修订由app层唯一拥有，不因页面拆分产生多份监听或事实来源。
- AppShell保存每页本次会话的滚动位置，ScrollArea仅提供受控viewport引用；切页布局完成后恢复目标页位置，不把多个页面的滚动位置混成一个，也不持久化硬件草稿。
- 原厂OpenKeyboard的能力绑定来自lighting/hotkey，keyboard请求进入灯光页；按键与热键策略仍归输入页。display及displayRotation进入显示页，在目标挂载后定位并确认已导航。托盘档案仍进入档案，最后访问页面复用页面注册表校验，不增加别名或旧控制台回退入口。
- 沿用tokens.css的冷灰表面、蓝色动作、绿色GPU与现有系统/用户字体；数据使用现有等宽数字。各页以语义SVG图标、比例环及模块间距组织，减少解释文字；短窗口侧栏保持可滚动，设置入口仍在底部。不开新主题或第二套控件。
- 更新页面接入校验、直接测试消费者及文档，移除控制台旧编辑器堆栈和旧锚点路由。预览、确认、恢复及原生IPC契约保持唯一领域所有者。
- 既有native.mjs同步十页导航、分类草稿与滚动验证。宿主源码仅使用Tao/Wry与数值缩放IPC，窗口隐藏、数据目录逐次隔离，不加载生产控制器；1450/9450端口必须空闲，连接后核对fixture URL。浏览器退出超时单独记录，不把用例通过等同整次命令通过。
- 档案相关的启动选择统一访问自动策略页，跨领域断言显式切到所属页。跨页事实刷新用例由同一组函数供Playwright和独立WebView2宿主执行，避免为了绕过Edge退出问题复制一份较弱断言。

## 备选方案

- 仅在控制台增加锚点按钮：仍堆在同一页，不满足用户要求，拒绝。
- 各页面复制编辑器或设备监听：造成多实例和并行状态，拒绝。
- 切页卸载组件：丢失草稿及待确认流程，拒绝。
