# Agent Note: 参照 Agent Switchboard 的完整软件偏好

Status: implemented

## 问题

用户要求软件偏好尽量对齐 agent-switchboard，完整实现且不保留兼容、过渡或重复路径。此前只有主题、自启、固定关闭到托盘和关于；主题单独写 localStorage，缺少窗口、外观和运行行为的完整保存与执行链。机器配置已归控制台，本次继续保持这一职责边界。

## 决定

- 关于页在实际版本号旁提供「更新日志」，复用共享详情弹窗和版本选择控件。构建直接内嵌仓库的 CHANGELOG.md，打开时加载，默认展示当前版本，按文档顺序提供历史与明确标注的未发布条目。发布流程仍以同一文件为准。

- 对照目标项目当前 AppSettingsForm，实现外观（主题、系统字体、90/100/110/125% 缩放、系统/减少动效）、窗口与托盘（关闭策略、置顶、自启、托盘启动、控制台/上次访问启动页、可录入快捷键）、运行日志级别、重启生效的渲染硬件加速和关于。遵守本项目中文单语及无云/账户约束，不复制客户端专属配置。
- preferences/ 领域拥有 app-preferences.json 的完整严格契约、校验、原子持久化和桌面执行/补偿。只有文件不存在才使用默认值；损坏、缺字段或未知字段拒绝读取并保留原件。旧主题 localStorage 读写及 lib/theme.ts 移除，不双读、双写或保留别名。侧栏与最近一级页面仍是独立布局状态；实际自启只走既有注册表接入，不在 JSON 内保存重复开关。
- App 根唯一调用 useAppPreferences，已确认值才驱动 appearance.ts；统一应用主题、字体和动效，真实桌面缩放由 WebView 拥有。保存先执行原生缩放、置顶、主题和快捷键，再原子持久化；任何失败都尝试恢复原桌面偏好，恢复失败保留具体诊断。读取、保存和重启互斥，失败可重试。
- 保存前重新读取并严格校验同一偏好文件，与已确认快照比较；进程启动后文件损坏或被外部改写时拒绝覆盖，要求重新读取。不让缓存成为绕过损坏保护的第二事实来源；拒绝发生在原生执行之前。
- 快捷键使用官方全局快捷键插件和标准物理键编码；换键先注册新键，再释放旧键，冲突保留原绑定，清理失败保留待清理记录。录入时抑制唤起行为，Esc、失焦、切页及卸载解除录入状态。系统字体使用 fontdb 枚举并接入统一 Select 的搜索能力；普通和搜索选择均使用 value/options/onChange(value) 当前契约，旧 Combobox 与原生 select/option 入口删除。设置只提供字体数据与读写，不自建下拉交互。
- 设置分组接入当前全局 Surface、Radio、Button、Switch 等原语；PreferenceCards 只组合设置领域的图形预览和文案，不拥有基础控件外观。预览颜色复用 tokens.css，动效同时尊重系统和用户的减少动效偏好。
- 关闭行为从固定隐藏改为已保存策略；启动窗口先隐藏创建，再根据偏好决定是否显示，读取/原生执行失败必须显示恢复界面。删除 --autostart 无条件隐藏分支，机器档案自动应用仍仅限该显式启动授权。
- 软件重启由 `startup/restart` 以当前可执行文件发起，沿用同一交接协议和登录自启参数隔离。新进程保留桌面唤回事件并等待原控制台及监护释放控制权，再初始化硬件。交接前失败可以在界面重试，交接后的启动失败显示原生诊断。
- 日志接入官方日志插件，保留具体错误与轮转文件，级别立即控制后续写入；静默不删除旧日志。硬件加速在创建 WebView 前配置，禁用时保留 Wry 默认参数，设置页根据当前进程的启动值显示是否需要重启。
- 同步模拟工具的日志依赖，并修正其直接包含逐键模块时暴露的路径与 Windows 特性声明；不增加第二实现。

2026-11-26 将界面默认字体固定为文泉驿正黑，读数、刻度及等宽字段使用 Google Sans Code。保存值 `system` 继续表示应用默认项，界面字体下拉保留系统字体选择。主窗口和屏显共用字体样式。安装包以独立文件分发字体、许可证和文泉驿正黑的可复现来源。Windows 使用只提供固定字体文件的应用协议，浏览器开发和隔离预览读取同一目录。

2026-11-27 用户要求设置页与配置档案采用同一信息布局，并保留现有 SVG 插画。设置页分为外观、窗口与托盘、启动、运行与诊断及关于。标题在组外，组内按行放置名称、说明和对应控件。主题与关闭行为保留现有图形单选，窄窗堆叠长控件。登录权限说明、更新和重启反馈归到各自设置行。

设置页采用居中的单列分组，移除页内搜索和分区目录。日志级别在运行与诊断的对应行直接调整。标题装饰图标居左，标题文案对齐。登录自启通过下拉选择或关闭。

## 影响与验证

- 2026-11-26 字体接入通过前端构建、Rust 类型检查、两项实际字形加载测试及两项深浅色宽窄布局检查。2.0.0 x64 安装包的内嵌 NSIS 引擎解包后，字体、许可和来源文件的 SHA-256 与仓库资源一致。隔离 WebView2 使用解包后的资源加载文泉驿正黑和 Google Sans Code，后者分别选中 600 与 400 字重。真实安装流程待验收。
- npm run build（三页接线与全局控件边界）、cargo check --offline --workspace、cargo check --offline --manifest-path tools/control-sim/Cargo.toml 和 verify-notes 通过。Rust 仅报告已有的增量缓存硬链接失败并自动复制。
- 15 项 preferences 聚焦原生测试通过：严格完整契约、启动后文件损坏及外部改写拒绝覆盖、原子文件保留、原生执行失败补偿、恢复失败诊断、完整偏好重载与重启状态、快捷键编码/冲突/清理、日志阈值、WebView 参数，以及普通重启参数与控制权等待/移交。文件只写 tempfile；控制权测试仅使用本次独立命名的内核对象，未接触实际控制者。
- 最终构建产物的 15 组隔离浏览器检查通过：五组偏好、旧主题路径失效、系统主题跟随与覆盖、字体搜索/预览/键盘、四档缩放、减少动效、窗口/托盘设置、自启回读、快捷键冲突和取消、日志级别、重启状态/失败重试/互斥、保存失败与防重复、最近启动页与重载、读取失败恢复、360–1440px 布局。无未捕获异常，已核对浅深截图。
- 浏览器 IPC、重启、自启及快捷键注册全部为隔离模拟；未修改真实用户配置、真实注册表、真实全局快捷键或硬件。尚未做真实 Tauri 桌面窗口、物理快捷键和 WebView 加速效果验收。未运行完整测试套件。

## 备选方案

- 只复制视觉并保留无执行链的开关：不能满足完整实现，拒绝。
- 保留主题 localStorage 与原生偏好双读：产生第二事实来源，拒绝。
- 直接使用 Tauri 原参数重启：会继承自启并可能重复应用机器档案，同时可能撞上旧进程/监护租约，拒绝。
- 全量复制多语言、云同步、账户和客户端专属设置：超出本项目软件偏好边界，拒绝。
