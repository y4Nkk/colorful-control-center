# Agent Note: 配置界面去说明化

Status: implemented

## 问题

配置页面重复展示用途介绍、执行流程与恢复原理，控件和实际数值被说明段落分隔。用户明确要求以原厂界面的配置密度为参考，保持自研外观，以图形、数值和操作为主。

## 决定

2026-11-18：全部工作区继承配置台布局。日常界面保留当前状态、常用输入、阻止操作的短原因；完整规格、诊断、事件与说明移入由按钮打开的对话框。概览先展示温度与读数，规格表退到信息入口；相同层级的模块使用等宽对齐网格，窄窗口顺序堆叠。参考 Apple HIG 的逐层披露、PowerToys 的同类设置分组和 Home Assistant 的状态摘要与详情入口。使用本项目的 SVG、主题令牌及预设图。

编辑器仍拥有草稿和领域预览。一页只有一个变更预览入口及一个恢复列表，可独立提交的设置共用一次确认，冲突或有独立试用/重启语义的设置各自确认。执行串行，提交前匹配已阅快照和可用性，发现变化或失败立即停止，保留未提交草稿。恢复按目标单独展示和确认。已有领域校验、系统授权、手动与自动显示试用及补偿继续生效。软件偏好即时保存的普通控件继续按现有语义管理。

监控首页对外统一称“概览”，导航、标题与启动页选择由现有页面清单接入；唤起整个应用的热键、托盘及窗口提示称“主窗口”，不把保留当前页面的窗口操作误称为进入概览。此为名称与语义图标修正，保留dashboard及openConsole等现有稳定标识，不变更持久化、IPC或导航行为。

扩展范围覆盖全部十个工作区及其当前可达子模块：概览、散热、性能、显示、灯光、输入、电池、自动策略、档案、设置。显示模式、白光键盘和供电来源增加绑定现有事实和明确草稿的语义 SVG；供电六条件改为紧凑图形规则卡，完整目标按需查看；USB 和网络使用离散状态图标。设置图形卡删除用途介绍字段及消费者；档案显示参数、绑定和实际执行结果。

新增图形所有权先登记DESIGN.md；图形只接收现有类型化数据，不新增硬件读取。未知、未报告、过期、保存配置、执行后回读与目标草稿继续严格区分。所有页面需通过跨页草稿/确认/恢复与宽窄深浅截图检查，选取可选键盘/灯条/电池能力场景补充覆盖；不运行全量测试套件或真实硬件。

显示与白光读取失败撤销对应Profile及图形，读取错误和动作错误分开，成功读取清除读取错误且保留未提交草稿；白光开关与保留亮度分别绘制。热键范围预览保留完整已选动作名及规则，复用已有展开项，不以仅显示数量替代授权目标。档案执行明细默认折叠，具体失败步骤直接可见，统一错误入口拥有播报，避免重复alert。界面结构变化后的检查先展开明细，并在实际所属工作区验证；不削弱旧修订、补偿、未知或独立确认的断言。

沿用项目灰白和蓝色令牌、语义 SVG 与 Lucide。预设卡片显示图形、名称和状态；性能开关与键盘功能采用紧凑分组；性能调节在宽屏并列。原理说明使用详情弹窗，恢复目标采用紧凑事实列表。校准保留接管影响，完整过程按需查看。

任务原始轮次调整展示层与文案。现轮次将确认入口与顺序协调移到页面层，预览目标、IPC、能力判断、轮询和草稿所有权仍由领域拥有。性能选项在共享恢复和外部回读后按上一份确认值逐项协调，保留实际编辑的目标，未编辑的开关随回读更新。短错误和操作阻止原因继续就地显示，完整信息按需阅读。

无法执行的模式与恢复仍保留其已读目标，由诊断弹窗查看。图形与初始值采用同一份模式结果，确认入口只在执行条件就绪时出现。

## 影响与验证

十个工作区及条件模块完成统一：复用现有语义图形和实际IPC，补齐显示模式、白光/三区键盘、供电来源、除尘状态及SVG时段图。设置选项删除用途介绍字段及其渲染/样式，删除旧三区i元素和时间条span绘制；错误、实际变更与恢复入口保留。所有新增图形不建立读取、控制或持久状态所有者。

2026-11-17 展示层改动通过 211 项聚焦模拟 IPC 检查（29 个检查文件）。80 张截图覆盖十页、360/1440 px、深浅主题和顶部/底部。额外验证逐键、多区、独立灯条、USB/LAN/PD、节能与校准、供电六条件、档案与自启，以及读失败、草稿保留、确认失效和失败补偿。

2026-11-17 安装包验证证据为 `target/ui-check/all-pages-ui-evidence.json` 与 `target/ui-check/all-pages-package-verification.log`。

2026-11-18 重新执行十页宽窄深浅模拟巡检，并聚焦验证页面提交、失败停止、旧预览失效、显示试用、共享恢复、供电暂停、热键跨页、宏录制清理及档案导入。171 项去重后的模拟 IPC 用例通过，80 张巡检截图与结果记录在 `target/ui-check/`。前端构建、控件边界与工作区 cargo check 通过。当前安装包摘要记录于安装包同目录的 `verification.json`。验证范围为隔离浏览器、编译与包内容。

## 备选方案

拒绝仅缩小字体、隐藏所有caption、删除预览恢复以及将原理介绍改成另一组常驻提示。
