# Agent Note: 原厂GPU Turbo事件与锁频恢复

Status: implemented

## 问题

FnKey 7.19.5.0的96/97号事件分别调用`GPU_Turbo_off`与`Load_GPU_forFn_3`，原热键路由未接入。它们操作GPU锁频与核心/显存偏移，不能与Turbo风扇、独显供电或单纯状态通知合并；恢复时还需保留应用前驱动实际锁定状态。

## 决定

- 事实源为Pi会话的FnKeyPack 7.19.5.0（SHA256 `aaa174b3e73d808e43891e14163f216ad2d9b90cd55c6d63d11cf2a266e7de18`）。本轮仅静态提取`ControlGPU.exe`（`6dc9cd2810470f6dd6fe07452d0120417ea3d1b59739ef7547e8793fa747e6ae`）及`NVGPU_DLL.dll`（`50a1a40a5f1fda3caa0e4c1a266b32e7db391fa842a402ed549e077f6ec90b43`），未运行或加载。辅助程序中的`set_lock_frequency`调用`Lock_Frequency(0, MHz)`；原厂DLL导出RVA 0x3C050将MHz乘1000，构造780字节版本2表并调用NVAPI ID `0x39442CFB`。其调用包装可在RVA 0x9D20静态核对。
- 相关GET接口ID `0xE440B867`及780字节结构可与[NvAPIWrapper的结构实现](https://github.com/falahati/NvAPIWrapper/blob/master/NvAPIWrapper/Native/GPU/Structures/PrivateClockBoostLockV2.cs)和[G-Helper的读取实现](https://github.com/seerge/g-helper/blob/main/app/Gpu/NVidia/NvidiaGpuControl.cs)交叉核对。必须按有效域和模式解析读回，严格校验数量、返回码、目标显卡身份，保留不属于本次写入的锁字段；失败保留原始锁表用于精确恢复。
- 96优先使用cmd4/sub9的温度限制值，若为0则使用实际显卡的基础图形频率。原厂`Get_GPU_Base_Clock`读取NVAPI基础频率，调用包装ID `0xDCB616C3`，结构版本0x30108；不依赖可能陈旧的page5初始化缓存。
- 97按page1[1]的实际原厂模式、cmd4/sub8声明的锁频与全模式超频能力、cmd4/sub9各模式频率、page5[16..23]已保存偏移和实际供电选择目标。性能模式在电池下只清偏移而不改锁频；安静、省电、娱乐按能力设置对应锁频及保存偏移或零偏移；模式4在原版switch中无操作。偏移编码使用原厂的负值编码规则，偏移最多处理前两张显卡，锁频只处理第一张。
- 已接入独立GPU Turbo热键范围与明确预览：确认页面列出当前状态、各模式/供电候选及不能执行的原因；长期授权绑定完整设备集合、能力、目标表、保存偏移及驱动范围，不把会随事件变化的即时锁频、模式或供电写入长期身份。事件执行使用当下模式/供电，并在每阶段重查已确认目标与本次快照，变化则停止并补偿。读取、预览不写缓存。锁频与偏移复用同一GPU控制所有者，按原厂顺序执行，失败按本次实际前态逆序恢复；首个基线与显卡断电、档案、单项调校互斥并支持重试。恢复不能把保存值当成实时回读，不调用原厂辅助程序或虚构成功。
- 修正普通GPU偏移与档案快照原先未绑定显卡的问题：首次基线和本次档案快照携带PCI、总线与插槽身份；改变显卡或顺序时拒绝向新设备写旧值。部分写入且补偿失败时保留设备绑定的原始kHz基线。锁频发送只含原厂两个目标域，准备读取失败不发送目标或补偿。

## 影响与验证

原厂模式/编码6项、Arg001事件9项、GPU控制26项、NVAPI布局/事务/函数指针桩28项、热键71项、GPU档案18项与独立假监护组合1项通过。GPU、屏幕按键和屏幕亮度18项模拟页面通过；宽窄深浅卡片已目检。前端构建、主程序和模拟宿主检查及26项控件检查通过；仅存在现有前端包体积与增量缓存复制警告。该阶段NSIS安装包已构建并通过静态内容校验；没有安装应用、加载真实NVAPI、执行辅助程序或物理GPU调试。

## 风险

锁表是私有NVAPI接口，驱动可能不提供或不接受对应版本；在GET或身份确认失败时禁止写入并显示确切原因。原厂辅助程序屏蔽了多数调用错误，不能以其退出码证明硬件操作成功。

## 备选方案

- 直接运行或打包原厂辅助程序：它吞掉错误且不提供可验证恢复状态，拒绝。
- 用其他显卡锁频工具或固定MHz猜测代替本机调用：不满足原厂模式和失败恢复契约，拒绝。
