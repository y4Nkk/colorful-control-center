# Agent Note: 磁盘卷占用分档配色

Status: implemented

## 问题

「本地存储」卡的卷容量条不随占用变化：磁盘用到九成以上仍是系列蓝，与用到一半的卷没有区别，百分比数字也一直是次级文字色。图表调色板只有系列蓝和一个警示红，没有中间档。

## 决定

每个磁盘卷按界面显示的整数已用百分比分三档。低于 80% 为正常，容量条沿用系列蓝，百分比沿用次级文字色；80% 起为偏高，90% 起为接近满，这两档的容量条和百分比数字换成档位色。分界取 80% 与 90%：90% 与资源管理器剩余约一成变红一致，80% 提供提前量。其余文字、图标和卡片边框保持中性。

档位由 `StorageVolume` 计算，写在卷列表项的 `data-usage` 上，取值为 `warning` 或 `alert`，正常档不输出该属性。档位与界面上的百分比取同一个四舍五入结果，避免显示 90% 却停在偏低档。`src/styles/monitoring.css` 只以该属性决定容量条填充和百分比颜色。

`tokens.css` 新增 `--ccc-chart-warning`，取 Tailwind 色阶的 yellow-700（浅色）与 yellow-400（深色）。浅色比其他图表色深两档，是为了让 12px 的百分比数字在卷底色上达到 4.70:1，与 `--ccc-chart-alert` 的 4.71:1 持平；yellow-500 与 amber-600 只有 2.07:1 与 3.08:1。警示红令牌本身也是浅色比常规深一档。

高对比度模式下容量条仍统一使用系统 Highlight，与其余图表一致，档位由百分比数字表达。存储详情弹窗的「总容量、已用与可用」说明补充一句变色规则。

## 影响与验证

占用变化的卷会在跨过 80% 与 90% 时变色。只按百分比判断：大容量卷剩余空间仍充足时也会进入高档，带盘符的小容量分区同理，本次没有加入绝对剩余量或卷容量下限。硬件读取与写入均未改动。

前端构建通过。`tools/ui-check/overview-visuals.spec.mjs` 新增用例，覆盖 79.4%、79.6%、89.4%、89.6% 四个边界与容量未知的卷，核对档位属性、容量条、百分比与说明文字，取色均来自令牌，与原有存储用例一并通过。亮暗主题与高对比度模式各截图核对一次，高对比度下三档填充同为一个系统色。界面用例在无头 Chromium 中以模拟数据运行，没有在真机上核对实际磁盘。

## 备选方案

- 连续渐变：占用接近的卷颜色相近，无法一眼分辨状态。
- 两档，90% 起变红：不需要新增颜色，但缺少提前量。
- 容量条用亮琥珀，百分比保持次级文字色：亮琥珀作小字对比度不足，需要第二个令牌。
- 红档追加绝对剩余量条件：多一个魔法数，等有实际反馈再加。
