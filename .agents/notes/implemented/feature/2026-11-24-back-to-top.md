# Agent Note: 工作区返回顶部

Status: implemented

## 问题

主工作区的长页面需要快速回到顶部。六个主页面共用滚动视口，电源设置与配置档案分别记住各自的位置。

## 决定

AppShell 在 ScrollArea 的固定外框中挂载 BackToTopButton。按钮位于右下角，AppShell 根据视口实际滚动位置控制显隐，在切换位置键时同步恢复。

按钮复用共享次操作样式和顶线箭头，激活时将焦点交回工作区视口。默认平滑滚动，应用或系统启用减少动效时立即返回。共享页面留白在底部保留按钮的操作空间。

## 影响与验证

- Chrome 测试覆盖六个主页面、电源设置和配置档案，验证位置恢复、键盘操作以及应用和系统的减少动效设置。
- 实际截图检查了浅色宽窗和深色窄窗的按钮、滚动槽与页尾间距。
- 前端构建、组件边界测试和 cargo check 通过。Edge 在当前环境启动时退出，浏览器验证使用 Chrome。

## 备选方案

独立滚动的页面可以各自挂载按钮。当前页面共用 AppShell 的滚动视口和恢复位置的逻辑。
