# Agent Note: 内置场景档案

Status: implemented

## 问题

首次打开配置档案时，用户需要先保存或导入一份个人设置。常用场景需要可直接预览并应用的起点。

## 决定

- 配置档案分为内置档案和我的档案。原生目录提供安静办公、移动续航和插电游戏，使用原厂安静、省电和性能模式。复制把预览的目标另存为普通个人档案，启动、供电和唤醒规则读取已保存的个人档案。
- 插电游戏在预览、应用和显示试用确认后复核交流供电，原厂模式事务校验固件资格。额定功率以机型标称为准。
- 同一组可选内屏刷新率目标用于三份档案。办公在本次运行由用户从本机候选选择，续航和游戏使用枚举的低、高档。Windows 活动显示路径识别唯一的非克隆内屏。自动刷新率持有设置时由自动刷新率继续管理。
- 内置场景与个人文件复用全域预检、差异展示、系统授权、显示试用、写入、恢复和报告。内置场景确认时复核原生解析的目标，个人文件继续核对磁盘修订。

- 配置档案按内置档案和我的档案纵向分组，档案整行可打开预览。选中档案或导入文件后，在独立面板展示差异，宽窗与列表并排，窄窗排到列表下方。打开时定位面板标题，收起时返回触发位置。当前值和目标值按列对齐，硬件预览、规则及应用确认继续使用原有流程。

## 影响与验证

构建、内屏识别和档案事务的原生隔离验证通过。模拟 IPC 验证覆盖首次入口、副本保存、规则列表、三份档案的模式与刷新率、自动刷新率归属及拔电恢复。实机的固件、显示路径和硬件写入待验收。

## 备选方案

带固定功耗或屏幕型号的模板需要维护逐机型参数及独立附件。以本机原厂策略和系统枚举候选解析目标可以直接使用现有预览和恢复机制。
