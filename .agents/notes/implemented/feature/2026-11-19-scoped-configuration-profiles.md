# Agent Note: 作用范围明确的配置档案

Status: implemented

## 问题

配置档案入口在零记录时同时显示空列表和占位预览。保存会捕获所有设备域，无法限定按场景切换的内容。手动预览缺少当前值与目标对照，覆盖时也看不到受影响的后台规则。

## 决定

- 保留系统二级标签及托盘深链。配置档案负责保存、导入、管理和手动应用。电源页拥有启动及供电规则，配置档案只展示引用及处理入口。
- 用户选择性能与散热、显示与显卡、灯光、充电与供电、设备功能配置组。后端只捕获所选组，沿用同一档案文件与可选字段。保存显示已捕获内容，手动应用展示能读取的当前值、保存目标、固件联动及阻止执行的原因。
- 创建、更新和导入共用原子保存，覆盖及删除核对已预览的文件修订。后台规则继续核对授权内容。显示试用和设置恢复沿用应用事务，显示结果来自实际报告。
- 首次入口集中保存和导入。已有档案时显示真实内容摘要、引用与差异。完整参数按需查看，删除无数据的详情占位与装饰图。

## 影响与验证

前端构建、控件边界、原生工作区检查通过。362 项 Rust 档案测试通过，包含注入隔离监护进程的显卡与软件曲线恢复用例。184 项模拟 IPC 浏览器回归通过，最终聚焦复测通过 23 项，涵盖按组保存、当前与目标切换、风扇曲线、覆盖后重新授权和显示试用。真机硬件写入与原生托盘待验收。

## 备选方案

整机快照作为唯一保存入口会将场景外设置带入切换。给档案另建配置格式会复制持久化与授权契约。
