# Agent Note: 原厂触摸板开关与完整事务

Status: implemented

## 问题

Pi真实FnKey.Features.GetI2C_TP/SetI2C_TP及CC40.Interface_Preference使用HKCU PrecisionTouchPad Status/Enabled读取当前值，通过Ctrl+Win+F24切换，page1[10]只保存偏好。FoundI2CHID使用HID类的I2C描述和有效设备节点检测；FnKey的252/253在I2C分支均切换，非I2C分支仅屏显，93另调用TPStatus，215还存在OLED息屏分支。不能把这些分支统一当成写入命令。

## 决定

- hal/touchpad只拥有只读设备识别、严格DWORD状态及系统切换；不写Windows状态注册表、不禁用PnP鼠标，不调用TPStatus或原厂事件日志辅助进程。依据Microsoft Enable/Disable Toggle Button及SendInput文档，输入串行提交，已有修饰键按下时拒绝，检查发送数量并回读状态。
- touchpad拥有设备集合、当前系统状态、原始OEM保存字节和本会话首次基线。读取不初始化偏好；未知系统状态禁止切换。所有目标绑定相同设备集合，旧预览拒绝；测试必须显式内存IO且原生模块不编入测试路径。
- 单项、独立热键授权及完整档案复用Scope/Plan。预览确认后切换及保存，逐阶段核对，失败补偿已尝试字段，失败记录可重试；初始恢复保留原始未知保存字节。档案独立保存系统目标和OEM偏好，不能压成同一个值。
- UI复用全局组件，左右展示当前状态和草稿，支持键盘操作、显式恢复及响应式模块间隔。TP灯光不在此域内。先核对当前/原始状态，再决定是否发送切换，避免重复操作。

## 影响与验证

完整单项、独立热键及档案捕获/严格文件/预览/手动/启动接入。9项领域、6项档案、2项显示组合及独立授权共18项原生检查通过，覆盖未知原始保存值、成功但无效果、逐阶段失败、本次补偿、首次恢复和设备替换。档案筛选285项通过（含11项显示领域复用，另2项要求显式注入的隔离设备组合保持忽略）、热键11项、核心事件5项通过。

72项相关页面组合通过，其中13项触摸板直接检查包含显示试用、导入导出、启动选择及深浅宽窄截图；宽窄卡片已目检。12项隔离软件风扇进程、主与模拟宿主离线编译、npm构建、26项控件及源码500/80限制通过。热键模式/风扇分支提取为各自操作函数，保持串行路由和函数边界，未保留平行写入实现。

仅内存、私有文件和模拟IPC，没有枚举真实设备、读取系统状态注册表、发送输入、调用OEM接口或执行物理验收；完整契约见docs/touchpad-contract.md。

系统输入可能被会话权限或当前键盘状态阻止；发送返回成功也不能代替触摸板状态回读。真实驱动行为和物理效果不由隔离测试证明。

## 备选方案

- 直接写Enabled或page1[10]：不是原厂实际切换链，也不能证明系统已生效。
- 通用鼠标设备禁用：与原版不符且会误及外接输入设备。
- 把93/215映射为无条件切换：缺少TPStatus的执行证据且破坏OLED分支，暂不加入可执行路由。
