# Agent Note: 托盘快捷预设和风扇

Status: implemented

## 问题

托盘可以唤起主窗口、预览性能档案和退出。隐藏主窗口后缺少预设切换、风扇控制和当前状态。

## 决策

右键一级菜单列出固件支持的预设并勾选回读档位。风扇子菜单提供交还固件控制、确认全速和直达散热设置。悬停显示分别回读的预设和风扇控制状态，并复用有效温度采样。统一的托盘导航事件处理散热设置和指定档案预览。

2026-11-23 托盘预设项增加对应的静态 SVG 小图。省电为绿叶、安静和静音增强为蓝月、娱乐为紫色环绕轨迹、性能为橙色风刃。矢量轮廓按菜单尺寸简化，配色取主图令牌。现有图标生成脚本将 SVG 栅格化，原生菜单用独立位图显示装饰，并用系统勾选表示回读档位。菜单析构后回收位图，图标加载失败时保留文字与操作。

预设与主窗口共用带修订的联动事务和原厂 FnKey 确认。预设会退出软件曲线时显式提示。全速确认绑定当前预设、风扇档位和软件曲线，确认后重新核对。风扇写入复用安全释放、固件能力检查和恢复逻辑。确认等待与实际事务的退出准入分开。执行后回读更新托盘，并通知主窗口刷新。

## 影响与验证

隔离验证覆盖 Windows 原生菜单的档位、勾选与动作映射、全速取消及状态变化、后台退出、档案预览、散热跳转和模拟硬件回读同步。完成前端构建与 Rust 类型检查。Windows 通知区域实际点击及实体硬件响应留待真机验收。

## 备选方案

由隐藏页面处理托盘写入会把后台硬件操作绑定到页面的挂载和响应周期。
