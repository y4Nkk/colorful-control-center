# Agent Note: 自定义窗口标题栏与可折叠侧边栏

Status: implemented

## 问题

用户要求软件侧边栏、关闭栏等参照相邻 agent-switchboard 项目，自定义实现，不使用 Windows 原生标题栏。改动前 AppShell 只有纯文字侧栏和页面顶栏，Tauri 仍显示原生窗口装饰，缺少应用内窗口控制和侧栏折叠入口。

## 决定

- 2026-11-13：按用户要求将侧栏手动折叠偏好持久化。AppShell 唯一拥有 `localStorage` 的 `ccc-sidebar-collapsed` 布尔字符串；首次使用默认展开，启动首帧同步读取，手动切换时同步保存后更新界面，不依赖退出事件或延迟 effect。保存失败沿用全局通知并保留已确认状态；窄窗口的自动折叠只影响显示，不写入手动偏好。复用现有 WebView 持久存储，不新增依赖、IPC、迁移或兼容路径。
- 2026-11-13：不超过 700px 时由窗口媒体查询强制使用图标导航，隐藏无可展开空间的折叠按钮；回到宽窗口恢复原折叠偏好。避免新灯光编辑器被展开侧栏挤出工作区。

- 沿用参考项目的两行两列外框：左侧导航跨两行，右上集成标题栏，右下保留工作区；设置固定在侧栏底部。
- 主窗口设置 decorations=false，显式声明 main 标签、最小尺寸 900×560；窗口仍可通过系统边缘调整大小。
- 自绘最小化、最大化／还原、关闭按钮；标题栏和侧栏顶部的非交互区域通过 data-tauri-drag-region 拖动窗口，并授权 Tauri 的拖动与双击最大化能力。
- 窗口命令由 commands/window.rs 薄层拥有，command_registry.rs 唯一注册，api/window.ts 类型化封装后由 client.ts 聚合；关闭调用 window.close()，继续触发既有 CloseRequested 隐藏到托盘逻辑。
- AppShell 唯一持有侧栏折叠偏好并保存到上述本地存储，224px 文字导航与 64px 图标导航切换。图标为应用内 SVG，不增加依赖。
- 复用现有颜色、字体、圆角、通知与 reduced-motion 令牌；最大化图标随窗口 resize 重新读取真实状态，窗口命令失败明确反馈。
- 用户补充要求侧栏和顶栏使用高斯模糊：主窗口启用透明 WebView 与 Tauri acrylic 背景材质，body 不再铺不透明画布，AppShell 唯一绘制共享的半透明底色和背景模糊；两块区域不重复叠加模糊，按钮与文字保持清晰，工作区仍为不透明实色。
- 模糊强度与浅深底色由 tokens.css 拥有，CSS 仅消费令牌；不添加材质设置项、运行时依赖或新的窗口命令。

## 备选方案

- 保留原生标题栏并额外绘制按钮：不满足用户要求，产生两套窗口控制，放弃。
- 引入 UI、图标或状态管理依赖：现有机制足够，使用局部 SVG 与 React 状态。
- 侧栏偏好另建 Rust 配置或通用状态管理层会增加异步恢复与第二套布局状态，既有 WebView 持久存储已满足本次需求，放弃。置顶能力仍超出本次范围；背景材质复用参考项目的透明窗口方案。
