# Agent Note: 电池SVG与真实读数联动

Status: implemented

## 问题

用户补充要求电量等模块采用对应的高质量SVG，并联动真实数据。现有电量与容量都使用通用圆环，难以直观区分电量和容量；读取失败仍保留旧Profile，会使画面及写入快照看起来仍然有效。

## 决定

由 BatteryOverview 拥有电池摘要，将电池图、百分比及供电与充电状态归在同一行。有系统估时时显示预计剩余时间。BatteryArtwork 绘制外壳、体积填充及充电标记，SVG 实例 ID 隔离。所有数值来自 BatteryProfile，未知与无电池用文字区分。OEM 满充与设计比例、循环次数显示在电池详情，保留原有阈值预览确认及恢复。

读取失败使Profile失效并禁用执行，草稿保持；读取成功清除读取错误，动作错误独立保留。轮询与页面激活沿用现有hook，不新增硬件查询、配置或第二个状态来源。删除被替换的通用电量圆环与旧布局样式。

## 影响与验证

22项相关模拟IPC检查通过，包含5项新电量图形检查以及充电、节能与校准回归。覆盖字段更新到SVG填充、充电标记、外接电源/电池供电、未知与零电量、容量大于设计值、读取失败撤销快照及恢复后的草稿保留；校准只用任务电量，不从阶段计算百分比，读取过期时图形为空。读数由外层meter拥有可访问语义，装饰与可见数字不重复建立status播报。360/760/1440宽度及深浅主题截图已检查，前端构建与源码限制通过。旧跨页互斥检查按当前工作区归属先进入性能页再检查模式，停止校准后返回复核。没有运行真实系统电源查询、原厂DLL、固件写入或硬件调试。

## 风险

Windows系统电源与OEM容量报告并非同一时刻的采样，不能由其中之一推导另一事实；容量百分比不当作厂商健康诊断。原厂原始容量未确认单位，不自行换算Wh。

## 备选方案

拒绝使用固定满电插画、把插电等同正在充电、把充电草稿用作实际电量，或给循环次数及校准阶段序号绘制伪造百分比。
