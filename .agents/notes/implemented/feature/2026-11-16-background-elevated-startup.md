# Agent Note: 后台规则的系统权限与管理员自启

Status: implemented

## 问题

原12项要求无人值守启动有真实授权方式，不能在启动时临时弹UAC。此前档案Binding只确认文件和稳定模式意图，GPU/LAN系统会话统一调用runas，而普通Run自启不会保留管理员令牌，因而后台系统权限缺少执行闭环。

## 决策

- 2026-11-17隔离复验发现，通用Session::prepare在已注入假启动器时仍查询真实令牌，造成后台GPU模拟被开发进程权限阻断。令牌到启动动作的判定统一由原生authorization::launch拥有；Session只保留并传递不可放宽的interactive限制。档案在显示等首个输出前的Permission.require_system预检保持原位，原生launch仍拒绝普通权限后台启动且不弹UAC。移除通用传输层重复的原生查询，不在测试中绕过真实启动器校验或修改运行令牌。

- hal/authorization拥有线程局部交互许可，RAII限制不可嵌套放宽，工作线程显式继承限制。启动及AC/DC/恢复档案、自动供电模式只沿用已有管理员令牌；已提升时直接打开同一程序，令牌查询失败不回退临时UAC。
- 完整档案依据实际GPU/LAN变更检查系统许可，发生在显示试用第一笔输出之前。显示确认后继续执行读取Pending保存的许可；无需系统权限的档案保持可用。
- startup/login拥有固定当前用户SID任务，只有当前可执行文件和--autostart参数，使用InteractiveToken及明确的普通/最高权限级别。设置页预览、二次确认、失败重读和首次前态恢复复用全局Select、ConfirmButton及Lucide图标。
- 当前任务、旧自启项、恢复记录及程序摘要绑定预览。首次实际前态在系统写入之前原子保存，失败补偿；失败恢复证据保留，可重新读取并恢复。旧Run项仅作为转换/恢复前态，确认配置后移除，不作为任务失败回退。任务结构、用户、程序或旧项属于其他目标时拒绝覆盖。
- 配置工作进程在HAL和窗口装配之前分派；固定请求复用保留会话、摘要及父进程许可。配置是已确认的持久操作，由本事务补偿和留存证据，父进程退出不撤销成功保存的登录配置。
- NSIS完整卸载先清理本软件任务，拒绝或失败保留程序文件；更新安装保留已确认任务。没有登录任务和旧项时不请求卸载提权。
- 删除旧bool自启IPC、即时Switch写入和注册表独立运行路径；类型化接口返回唯一系统快照，不在软件偏好保存重复开关。
- 自启读取或保存失败后缺少有效快照时，当前权限显示未知，不能由空值推断当前进程是普通权限；重新读取后恢复实际权限展示。

## 验证

- 7项登录任务内存测试：固定XML、转义、陌生任务/用户/额外动作、旧预览和记录、旧Run转换、多次设置的首次恢复、各写阶段故障及补偿失败后的恢复。
- 3项权限限制纯逻辑测试：禁止后台UAC、嵌套不放宽及跨线程传递。
- 31项显示组合档案回归：新增四种后台来源在系统权限缺失时零显示/硬件输出，普通档案不强制提权；保留许可、撤销和显示恢复链通过。
- 4项模拟IPC页面测试：二次确认/初始恢复、失败及外部变更、切换草稿撤销旧确认、浅/深主题与360/1440布局；截图已目检。
- npm run build、cargo check --offline --workspace通过；当前644个Rust/255个前端文件长度检查无超限。共享会话9项GPU/6项LAN隔离进程回归通过，覆盖多阶段、父进程退出、取消与同进程补偿。最终安装包另做静态校验，不执行程序。
- 2026-11-17 Release编译完成，NSIS下载在受限环境DNS失败后复用已编译产物单独打包成功；包为10,891,393字节，SHA256 `09459a3ef9bff8f64a18823d2a1da84e9ada8cb7944d2741f7f15b0a7e422684`。7z全包校验、AMD64、前端资源、七个工作进程及电池音频恢复入口通过；包内程序与同次编译产物只有官方UNK→NSS标记替换，运行时输入无晚于编译的改动。证据见target/ui-check/package-verification.json、bundle-20261117.log与login-startup-evidence.json。

## 影响与验证

未注册或删除真实任务、未修改真实Run项/用户配置、未执行UAC/原生登录启动/卸载，也未调用任何硬件接口。Windows任务服务、真实登录及卸载提权效果尚未验收；不能把内存与模拟页面通过表述成本机已配置或物理验收。

任务权限遵循[Microsoft任务安全上下文](https://learn.microsoft.com/en-us/windows/win32/taskschd/security-contexts-for-running-tasks)和[RegisterTask契约](https://learn.microsoft.com/en-us/windows/win32/api/taskschd/nf-taskschd-itaskfolder-registertask)。NSIS钩子及UpdateMode取自本机已生成的installer.nsi与安装的Tauri配置schema。

## 备选方案

- 继续使用Run项并在后台临时runas：不满足无人值守授权要求，拒绝。
- 保存档案Binding后直接报告系统权限已授予：混淆软件意图与Windows令牌，拒绝。
- 新建通用提权服务或任意命令代理：超出固定登录任务需求，拒绝。
