# Agent Note: 侧栏反馈入口

Status: implemented

## 问题

用户希望从各个工作区都能找到公开的反馈入口。

## 决定

侧栏底部在检查更新与设置之间提供「反馈」。按钮沿用侧栏导航样式，折叠时提供键盘和指针提示。通过现有外部链接能力打开项目的 GitHub Issue 类型选择页，打开失败时使用全局错误通知。

GitHub 提供问题反馈和功能建议两种表单，用户自行填写并提交。

## 影响与验证

短窗口的底部操作使用现有紧凑控件高度，为工作区导航保留滚动空间。隔离浏览器用例覆盖底部位置、折叠提示、键盘触发、外部链接目标和短窗滚动。

## 备选方案

应用内表单会增加 GitHub 登录和提交状态的维护。直接使用仓库已有的 Issues 功能可以沿用用户的 GitHub 会话。
