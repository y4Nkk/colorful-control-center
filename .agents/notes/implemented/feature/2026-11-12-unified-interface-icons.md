# Agent Note: 全局界面图标

Status: implemented

## 问题

用户要求参考 agent-switchboard 优化图标。改动前 ShellIcon 混用导航与窗口尺寸，导航没有轮廓／实心两态，设置齿轮不对称；主题选中图标和通知关闭字形各自实现，通知种类仅用彩色圆点表达。

## 决定

2026-11-16用户明确要求引入开源图标库并全局应用，取代原自绘图标决定。采用Lucide React官方包（ISC许可），仅Icon.tsx显式命名导入，用语义名称统一导航、窗口、模块标题、操作与反馈。删除旧手写路径、轮廓/实心双图和weight契约，选中导航通过同一SVG描边表达；不把领域图表、品牌标识或精细硬件插画替换成通用图标。Button允许显式icon，ConfirmButton仍保留原两步确认并显示确认状态图标；装饰SVG不重复朗读，中文可访问名称与实际行为保留。依赖与锁文件同步，检查构建、边界和隔离宽窄/深浅主题界面；不启动真实控制器或硬件写入。官方来源：https://lucide.dev/guide/react/ 、https://github.com/lucide-icons/lucide/blob/main/LICENSE。

以下记录原自绘实现及其历史验证；本次库迁移验证以补充结果为准。

本次已安装lucide-react 1.73.0，唯一Icon边界覆盖控制台、设置、档案子模块标题以及101处显式操作入口；执行结果用具名图标向辅助技术表达成功/失败，其他装饰图标不重复朗读。旧手绘通用路径、双态分组与weight属性已删除。新增AST边界拒绝业务直引图标库，27项控件边界检查通过；隔离Edge的16项图标、GPU图示、模式与热键预览检查通过，并检查1440浅色与700深色截图。构建已通过，最终合并验证继续随当前档案工作进行；没有启动真实原厂程序、控制器或硬件写入。

- 采用参考项目的视觉层级：24px 导航轮廓／实心两态、20px 折叠及反馈图标、16px 窗口按钮。使用自绘本地 SVG，不新增依赖；颜色与尺寸消费全局令牌。
- components/Icon.tsx 拥有全部界面符号，替换 app/ShellIcon.tsx；页面到导航图标的映射由 SideNav 唯一拥有，PageId 仍来自 navigation.ts。
- 控制台用调节滑杆、档案用叠层、设置用对称六齿轮；图标两态共用同一画布，随 aria-current 对应的页面事实切换，保持图形中心与尺寸稳定。
- 折叠使用同一个双箭头图标旋转，窗口按钮统一小尺寸线条；主题选中与成功通知复用圆形勾，通知增加信息、警告与错误符号，关闭使用统一 X。
- 图标均为装饰性 SVG，中文名称与状态来自原有按钮或文字；动画服从 reduced-motion。图表、示意画和品牌风扇图标继续由各自所有者负责。

## 影响与验证

- 导航、窗口按钮、主题选中标记与通知接入唯一 Icon 组件；旧 ShellIcon 文件、ccc-shell-icon／ccc-toast-dot 样式、主题独立 SVG 和字符关闭实现已移除，无兼容别名和新增依赖。
- npm run build（TypeScript、三页边界检查与 Vite）和 cargo check 通过；源码及 DESIGN.md 中旧图标引用清理检查、差异检查通过。
- 隔离浏览器验证了三页轮廓／实心切换、选中态无位移、对称齿轮中心镂空、折叠双箭头旋转、64／224px 侧栏、16／20／24px 图标尺寸、浅深主题颜色、唯一主题选中标记、四种通知形状及 SVG 关闭操作；全部图形位于 24 单位画布内，保持 aria-hidden、focusable=false 与 pointer-events:none。
- 窗口最大化／还原图标随模拟 resize 事件更新，最小化与关闭仍发送原有命令；本次测试没有执行真实系统或硬件写入。临时 Tauri 事件模拟器未使用 StrictMode，避开其清理回调问题；产品 StrictMode 与窗口逻辑不变。
- 测试夹具、预览入口和服务位于会话 scratch，不写入产品页面；图标动画继续消费全局 reduced-motion 令牌。全局 verify-notes 在实施阶段通过，落地后再次校验。未进行本轮真机窗口操作或截图视觉核对。

## 备选方案

- 引入两套图标依赖复制参考项目：当前只需少量符号，自绘 SVG 能保持一致而不增加运行时依赖。
- 只调大旧图标：无法解决不对称轮廓、状态不明确和多处实现的问题。
