# Agent Note: CPU、GPU 与内存监控读取

Status: implemented

## 问题

聚合 CPU 频率无法表达活跃处理器的频率。显卡静态字段与传感器同频读取，内存固件资料只展示速率，显示采样每拍重复读取风扇通道与原厂内存报告。

## 决策

- 同一 PDH 窗口逐逻辑处理器配对，只有窗口两端基频一致且活跃实例数据完整时才计算加权及最高活跃频率。效用独立报告。
- 概览的 CPU 活跃频率数字从现有历史中取值。当当前效用样本有效而频率缺测时，可沿用不超过 2.5 秒的最近有效频率。效用无效或采样中断时结束沿用。频率短折线使用原始样本，缺测窗口保留断点。
- 从 SMBIOS 系统内存阵列解析设备、可识别的物理插槽用量与共同配置速率，设备信息部分有效时保留。
- GPU 详情只在打开、可见及连接可用时按 5 秒刷新。静态数据和字段能力绑定连接，驱动失效后释放连接。显存容量占用率由同次内存查询的已用量与总量计算。
- 显示端缓存风扇掩码与原厂参考频率 30 秒，原厂报告频率 5 秒。断连及系统唤醒使其失效。显示周期以单调时钟对齐，错过的采样拍跳过。控制与监护实时读取。

## 影响与验证

137 项 Rust 聚焦检查通过，覆盖 PDH 睿频、空闲和缺测，SMBIOS 混合与板载设备，GPU 字段支持和连接替换，缓存首次、命中、过期、断连恢复与定周期跳拍。生产构建通过 50 项隔离浏览器检查，其中 GPU 详情覆盖首次读取、关闭、隐藏、暂停和切换连接。前端完整构建、workspace 类型检查与 Windows GNU 主程序构建通过。

普通权限真机确认 20 个 PDH 实例、两条 16 GiB 内存及共同配置速率 6400 MT/s。现有 NVIDIA 驱动返回编解码利用率、PCIe 链路及性能状态，显存温度和目标风扇转速留空。以相同显示采样入口对比 15 组每拍冷读与按期缓存，DCHU 锁内 P95 为 99.3 ms 与 62.2 ms。外部频率对照、实际睡眠恢复和独显断电恢复单独验收。

频率闪烁复核中，只读采集 22 个一秒窗口，其中一次逻辑处理器的 `% Processor Time` 无效，按现有完整性规则该窗口无法估算频率。概览浏览器回归覆盖这类间歇缺测、连续缺测、采样中断和恢复。

## 备选方案

聚合频率只用于基线对照。额外 GPU 字段和 DCHU 退避分别由详情请求与显示采样管理。
