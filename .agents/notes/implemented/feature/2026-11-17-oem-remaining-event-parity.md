# Agent Note: 剩余原厂事件接入与适用边界

Status: implemented

## 问题

静态逐项比较FnKey/Form1.Arg001_GetEvent的88个case与ccc-core/oem_events，发现19个未映射分支。不能以已接入25个授权范围代替全部原厂事件已完成，也不能把其他机型或不可达分支变成本机动作。

## 决定

原厂240/241只显示FlexiCharger开始/停止充电报告，归入既有状态通知，不修改充电或节能策略；通知能力标识更新，旧确认不隐式覆盖新增报告。132仅打开control.exe /name Microsoft.Recovery，新增独立systemRecovery授权，默认关闭，沿用预览确认和软件策略恢复，不自动执行系统还原/重置。系统目录与程序摘要绑定授权，执行前复核，取消、录制和原厂控制权互斥均先检查。

其余本机分支已按原厂调用链实现：72为关机事件，192按计划执行合盖动作；84由NVSR/OLED条件决定；133使用121/26和原厂专属设备接口。最初已展开目录未包含两个原厂助手，安装包清单实际包含；已从本机FnKey.appxbundle的7.19.5.0 x64载荷精确提取并保存摘要。Windows无线API研究只作对照，不形成运行时替代或回退通道，不加载这两个OEM助手。

飞行模式DLL SHA256为87351eeb1ce422d9352d6c7df1fadec0b9a000c6efcf19ed68f1b2b035b10949。SetAirplaneMode在RVA0x2660使用专属接口GUID 6e59105f-34e7-4b3c-b676-c5c8233c008d，通过IOCTL 0x00322804发送1字节绝对0/1，无输出包。前置121/26同步沿用FnKey；系统事实只读SystemRadioState原始REG_DWORD，不沿用原厂缺失时默认0的行为。自研传输必须绑定设备、回读系统报告、首次恢复与失败补偿，不把单独无线网卡开关当飞行模式，也不加载OEM应用执行入口。

cc30wk SHA256与既有NVPCF证据一致，实际命名空间CC30Workaround；0x0025参数2只调用一次AuxSwitch。AuxSwitchCC30.dll SHA256为01c948638e11b5820f4d9cb07be04e6c7f2931fe46754e777bb75e59996e6aa0，静态核对得到CUI类7160a13d-73da-4cea-95b9-37356478588a、接口f932c038-6484-45ca-8fa1-7c8c279f7aee、枚举slot12及请求slot44；148字节包为适配器UID/8/132/0x721及132个零字节，请求GUID bfb9816c-aeb0-434b-99f3-0f94e6bebf0d。必须先匹配原厂NVSR EDID及WMI84分支，OLED94/1独立判断。原始反编译、汇编和结构事实在target/oem-static/fnkey-current/，仅静态读取，无原厂函数或硬件调用。

72与192分别独立授权，不能继承低电量动作许可。192绑定活动计划、AC/DC合盖动作及现代待机支持：0不操作、1在S0平台关闭显示/其他平台睡眠、2休眠、3关机；供电与计划在请求前复核。沿用Windows现有计划，不新增合盖设置。显示关闭保留MonitorControler的200ms可取消等待，Windows消息使用有效的HWND_BROADCAST。实际睡眠/关机不在HAL锁内等待，系统调用失败保留诊断；恢复只还原软件策略，不承诺撤销已发送的系统请求。睡眠与关机的系统原语收敛到HAL，低电量入口复用，权限仅启用当前令牌已拥有的SeShutdownPrivilege并恢复原标志，不发起UAC。

65–71属于NHxxAC/AF的AMD热/功率联动，必须保留原厂机型适用边界，不对本机Intel目标输出AMD命令。93为空分支。301–304在Arg001路径不可达：唯一调用者将事件与0xFF按位与；不能扩大解码字宽或建立别名使其误触发其他低8位事件。

## 影响

事件核心语义、热键范围/授权、原生运行入口、类型化API、模拟IPC和范围预览同步更新。已有读数、硬件初始恢复和明确授权边界保留；新增入口不增加独立参数或第二套硬件状态。

## 验证

217项相关Rust聚焦检查通过：热键189、飞行模式6、CUI固定ABI及请求包2、核心事件20；包含既有回归，不作为全新用例数。14项系统事件与飞行模式模拟页面检查通过，另3项独显页面通过。旧独显检查仍在显卡页寻找已经移到控制台的监控状态，已按真实页面所有权修正；共用模拟事件发送器复用唯一emit，不维护第二份监听循环。前端构建与workspace编译通过，676份Rust及363份前端相关文件的行数检查无错误。宽窄深浅飞行模式截图已检查。未进行实际事件监听、系统动作、无线接口、CUI请求、原厂DLL加载或硬件调试。

飞行模式的手动卡片与热键共享Controller及首次基线；取消或部分失败恢复本次前态，来源变化保留错误及基线，不在未知报告下假造状态。NVSR与OLED独立请求，激活只做适用NVSR启动修复；84还唤醒OLED。系统操作原语收敛到HAL，原有低电量分支复用，不增加独立配置。对88个原厂标签逐项分类：76个已有映射，7个AMD专用、1个空分支和4个在低8位路径不可达；没有遗留本轮19项中的本机可达缺口。

## 风险

报告只代表原厂事件，不能证明电池此刻实际充电。系统恢复入口只打开Windows界面，后续Windows操作由用户自行发起；软件策略恢复不关闭或回滚Windows操作。

## 备选方案

拒绝将缺口统一标为不支持、读取配置时执行动作、扩大已有系统动作权限、直接启动OEM软件代替自研实现，或用单独无线网卡开关冒充系统飞行模式。
