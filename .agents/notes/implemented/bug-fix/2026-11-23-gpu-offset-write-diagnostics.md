# Agent Note: GPU 单项偏移写入权限与失败回读

Status: implemented

## 问题

GPU 单项调校在普通权限下仍允许提交，首次 NVAPI 写入的底层错误被外层描述遮蔽，补偿失败后界面沿用写前读数。

## 决定

单项 GPU IPC 复用 Windows 提升令牌检查，读取仍返回偏移和写入受限原因。首次事务错误保留完整链路，回滚错误独立报告。回滚失败后重新读取实际偏移，保留用户编辑的草稿。读不到当前偏移时撤下旧值，显示原因和重试入口。

## 影响与验证

28 项 NVAPI 模拟测试、4 项 GPU 界面测试、前端构建及 Rust 编译检查通过。真机管理员权限下的 GPU 写入、回读与恢复尚未验证，提升后驱动仍可能拒绝调用。

## 备选方案

单项写入复用当前进程的管理员令牌。GPU 卡仅在当前账户具有可提升的受限令牌时提供显式确认的管理员重启。无同账户提升资格时显示原因，后端也在启动 UAC 前复核。设置页的管理员登录启动继续由现有计划任务配置拥有。

## 管理员重启交接

普通应用重启和管理员重启共用 `startup/restart`。新进程验证身份并保留桌面唤回事件后回报就绪。旧进程优先识别子进程退出，在退出状态锁内提交许可；取消或超时通知新进程结束。新进程只接受明确交接许可，等待旧进程及独立恢复任务结束后装配硬件。获准前失败由原窗口反馈，许可后的启动失败由 Windows 原生对话框显示原因和重试方式。重启不携带登录自启参数，也不提交 GPU 草稿。

本轮通过 33 项启动、1 项退出状态、41 项 NVAPI 与单项偏移、9 项独显授权进程和 9 项界面回归。Windows 隔离实验验证同一账户不同完整性令牌的事件访问边界。较宽 GPU 组在同一普通令牌下对比修复前后的二进制，均为 90 通过、相同 11 项失败，首个失败由测试缺少管理员令牌触发。正式 UAC、主窗口唤回及 GPU 真机写入和恢复仍待验证。
