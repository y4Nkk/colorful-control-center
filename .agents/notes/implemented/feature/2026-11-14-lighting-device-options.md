# Agent Note: 灯光闲置、开机与外围灯区

Status: implemented

## 问题

现有三区与逐键灯效不编辑原厂闲置关灯、开机覆盖、Logo和灯条。三区恢复还回写整个page2保存块，会覆盖独立睡眠、逐键参数和外围灯区；bit15固定按TP解释，在灯条型号上错误。

## 决定

- 以本机kbled 6.26的BaseKB、RGBKB、KBModule、InsydeAcpiProt和FnKeyPack的Features为依据。闲置关灯保存page2[36..40]（触发、时分秒），cmd121/sub24发送seconds<<8|255或0；原厂界面允许5..7199秒。开机覆盖能力为cmd13 byte43 bit0，保存page2[7]，cmd121/sub30值0/1。
- Logo与普通灯条能力取page7 v1.0的WMI122（bytes6..9）bit18/12，仅原厂三区家族采用cmd103 F6/F3颜色和E0掩码。未知版本不从整数回声或已有保存颜色猜能力；X170独立协议见2026-11-14-x170-light-bar笔记，新多区灯条继续追踪，不冒充普通灯条。
- lighting/options拥有7、36..40、100..108；lighting/transaction恢复只写三区/白光所属字段。全局E0掩码发送必须重新组合当前键盘、TP/Logo/灯条保存事实；恢复保留其他域的新值。逐键矩阵和动态参数不由options写入。
- TP保存96..100和旧RGBKB的掩码已定位，但当前原厂UI未发现独立颜色执行路径或明确LED能力；继续静态追踪，不将触控板设备支持位冒充RGB灯支持，不臆造颜色命令。
- 前端共用 Surface、Switch、Input 与页面级预览确认。闲置和开机为一组，外围灯区按支持能力显示独立颜色和开关草稿。预览绑定修订与目标，失败恢复本次前态，首次基线供用户重试恢复。
- 2026-11-18 闲置关灯以时、分、秒编辑，预览时换算为原契约的整数秒。分量为空、越界或开启后不足 5 秒时不可应用。开机覆盖和外围灯区继续走同一灯光选项事务。
- 2026-11-19 灯光策略复用键盘页右侧的详情与重新读取操作。闲置关灯、开机覆盖和可用的外围灯区共用顶部标题和开关行，其余控件在该行下方排列。
- 开发模式重挂载或快速离页后重进会取消旧读取；新的进入等待旧请求完成再读取，避免依赖5秒轮询解除首次加载。X170组合回归复现窄屏首次读取超时后修复，保留草稿与能力归一化语义。
- 移除已不能满足共享能力预检的“未知类型手动选择RGB/白光”入口；读侧保留未知及重试，执行侧只接受实际识别家族。类型和普通灯条能力在控制锁内重新确认，避免界面可选但后端不能执行的分支。
- 共享模拟IPC按电池、校准、节能、灯光、性能、显示/显卡和软件等职责拆分函数，仍在同一个注入闭包中组合；保留状态和原有命令语义，避免新增功能继续扩大单个超长分发函数。

## 影响与验证

- 2026-11-18 Edge 模拟 IPC 验证时、分、秒越界拦截，7199 秒换算，关闭计时保留预设，以及重读、切页、确认、恢复和顶盖能力移除。

新增3项类型化IPC与控制台卡片；原生内存传输覆盖编码、能力隔离、旧预览、共享字段保留、保存/命令部分失败和恢复重试。灯光域44项与7项新增页面检查已通过，组合键盘/逐键/电池/节能/性能/显示/显卡页面42项通过。npm run build、cargo check --offline --workspace及control-sim编译通过。宽/窄截图已检查，360px无横向溢出；没有调用实际DLL、HID或驱动。

三区恢复删除整块page2回写，改为32、35、80..96的所属字段；白光仅35、80。原始关闭状态不因保存非零亮度而点亮，恢复掩码组合当前外围灯值。前端只列有变化的预览行，未知/无能力项目不显示编辑器；读取失败撤销可执行快照，保留草稿和诊断，能力变化时去除已不支持的草稿字段。

## 风险

保存值回读只证明设置事务，不能证明实际亮灯或超时行为。原厂后台共存、设备睡眠恢复和物理效果不在本轮执行范围，亦不阻止代码继续补齐。

## 备选方案

- 继续整块恢复page2：覆盖逐键、睡眠和外围灯区，拒绝。
- 复用WMI96 bit12推断灯条：该位为DTT；普通灯条为WMI122 bit12，拒绝混用。
- 为TP猜颜色命令或把其他型号多区/HID灯条当作普通灯条：没有本机执行链证据，继续静态追踪对应分支。
