# Agent Note: 配置界面去说明化

Status: implemented

## 问题

配置页面重复展示用途介绍、执行流程与恢复原理，控件和实际数值被说明段落分隔。用户明确要求以原厂界面的配置密度为参考，保持自研外观，以图形、数值和操作为主。

## 决定

2026-11-19 各工作区采用与设备配置相同的操作路径。独立开关和离散选项由用户事件提交，使用领域快照、校验、互斥及回读。曲线、连续数值、相互约束的参数、按键映射和档案等组合编辑在所属模块应用或恢复。移除页面级动作注册、跨模块提交分组和底栏。系统授权、显示试用、原厂进程交接和重启仍由对应模块或既定专用会话呈现。独立切换只提交所属字段，其他有效草稿保留。

2026-11-19 开关、单选和动作按钮承载它们已经表达的状态。各工作区移除紧邻控件的常态启停和选中文案。草稿与回读不一致、部分设备状态混合、执行进度、暂停原因、重启和恢复条件继续显示。详情、应用预览和恢复目标按所属事务展示实际值。

2026-11-19 设备配置按控件提交。屏幕、自动刷新率、显卡模式、独显电源、键盘功能、触摸板、麦克风和飞行模式使用当前回读生成领域请求，切换后回读，并在提交期间锁定同一模块。移除该页的草稿、提交分组与页底操作栏。初始恢复移至各模块。手动显示直接开始试用，屏幕卡保留 15 秒撤回与保留。自动刷新率开关直接启用或恢复，沿用独立监护与跨页试用入口。显卡模式按钮提交选择，卡内只在待重启时提示目标并提供显式重启操作。自动刷新率以扫描纹理读数面板和低刷、恢复两档显示离散频率，供电和模式绑定当前回读。

2026-11-19 合并重复读数和入口。系统概览从现有硬件显示采样中读取原厂当前模式，以名称和一张模式插画展示。性能调校独占预设选择与恢复。概览的 CPU/GPU 圆环统一数值和单位的行高与对齐，规格入口位于插画或标题旁。规格、说明及诊断入口统一使用共享的单信息图标按钮，可访问名称沿用原有标签，悬停显示弹窗标题。内存图表标题显示五分钟范围和最新采样时刻。电源页的常驻供电状态与电量图由电池读数统一展示，策略独立读到的供电状态和校准任务电量可在各自详情查看。

性能档案列表显示保存日期，选中档案的参数在页内预览一次。提交不可用时，页内仍可查看参数并保留禁止提交的校验。导入文件日期在导入预览显示。自动与档案刷新率试用的目标与倒计时由对应确认区展示，屏幕模块指向实际确认入口。手动试用在本地确认。白光档位由滑杆显示，示意图保留关灯时的保留档位。热键详情的两项低电量诊断在供电与电量一致时共用一行，分别报告的不同读数随其各自规则展示。

2026-11-18 移除配置台的装饰性胶囊标签。状态、告警、倒计时和限制用普通文字表达，编辑器的变更及联动复用 `FactList`。预设模式直接由卡片提交，卡片显示设备回读的当前状态。控件标签与可访问名称继续描述实际输入和操作。

2026-11-18 应用设置改为页面内实时差异和一次明确提交。后端权威预览及修订检查继续由领域拥有。当前页面有多种事务时先选择范围，展示对应的当前值、目标和影响，再点应用或相应试用按钮。普通应用不再开启确认弹窗。恢复仍显示独立目标，重启、校准、除尘及显示试用的保留或取消按现有独立动作处理。原厂静态核对中，风扇和节能保存直接执行，独立 GPU 超频另有确认对话框。项目将 GPU 的变更及实际执行按钮合到页内。

2026-11-18：全部工作区继承配置台布局。日常界面保留当前状态、常用输入、阻止操作的短原因；完整规格、诊断、事件与说明移入由按钮打开的对话框。概览先展示温度与读数，规格表退到信息入口；相同层级的模块使用等宽对齐网格，窄窗口顺序堆叠。参考 Apple HIG 的逐层披露、PowerToys 的同类设置分组和 Home Assistant 的状态摘要与详情入口。使用本项目的 SVG、主题令牌及预设图。

此前的页面级预览与恢复分组已由 2026-11-19 的模块内操作取代。编辑器仍拥有草稿及领域校验。显示试用、系统授权、初始恢复和重启沿用各自的执行条件。

监控首页对外统一称“概览”，导航、标题与启动页选择由现有页面清单接入；唤起整个应用的热键、托盘及窗口提示称“主窗口”，不把保留当前页面的窗口操作误称为进入概览。此为名称与语义图标修正，保留dashboard及openConsole等现有稳定标识，不变更持久化、IPC或导航行为。

扩展范围覆盖全部十个工作区及其当前可达子模块：概览、散热、性能、显示、灯光、输入、电池、自动策略、档案、设置。显示模式、白光键盘和供电来源增加绑定现有事实和明确草稿的语义 SVG；供电六条件改为紧凑图形规则卡，完整目标按需查看；USB 和网络使用离散状态图标。设置图形卡删除用途介绍字段及消费者；档案显示参数、绑定和实际执行结果。

新增图形所有权先登记DESIGN.md；图形只接收现有类型化数据，不新增硬件读取。未知、未报告、过期、保存配置、执行后回读与目标草稿继续严格区分。所有页面需通过跨页草稿/确认/恢复与宽窄深浅截图检查，选取可选键盘/灯条/电池能力场景补充覆盖；不运行全量测试套件或真实硬件。

显示与白光读取失败撤销对应Profile及图形，读取错误和动作错误分开，成功读取清除读取错误且保留未提交草稿；白光开关与保留亮度分别绘制。热键范围预览保留完整已选动作名及规则，复用已有展开项，不以仅显示数量替代授权目标。档案执行明细默认折叠，具体失败步骤直接可见，统一错误入口拥有播报，避免重复alert。界面结构变化后的检查先展开明细，并在实际所属工作区验证；不削弱旧修订、补偿、未知或独立确认的断言。

沿用项目灰白和蓝色令牌、语义 SVG 与 Lucide。预设卡片显示图形、名称和状态；性能开关与键盘功能采用紧凑分组；性能调节在宽屏并列。原理说明使用详情弹窗，恢复目标采用紧凑事实列表。校准保留接管影响，完整过程按需查看。

预览目标、IPC、能力判断、轮询和草稿继续由领域拥有。性能选项逐项提交并回读，初始恢复复用模式快照。短错误和操作阻止原因继续就地显示，完整信息按需阅读。

模式切换失败显示短原因并回读。受限的恢复目标可在诊断弹窗查看，恢复入口在执行条件就绪时开放。

2026-11-19 模块布局由父容器统一定义。`module-layout.css` 管理工作区纵向与分栏轨道和间距，整行模块沿内容区的边缘拉伸。区块表面只安排内部控件，构建检查其根节点及附加样式的宽度、行内外边距和网格定位。使用工作区巡检验证每张卡片填满所在列。

2026-11-19 模块内部以标题、留白、对齐与表面色分组。移除充电设置、事实行、执行记录、模块操作、预览分组和对话框头尾的横线，并删除原生托盘菜单的分隔项。数据刻度、图例和独立表面边缘表达各自的语义。

2026-11-19 页面标题与对应区域的可访问名称复用导航定义。CPU 功耗与电压、独显电源、USB 选择性暂停使用同名标题、区域或档案预览。新建档案示例使用通用名称，测试通过档案名标签定位输入框。

2026-11-19 继续统一概览、温度趋势、触摸板、麦克风静音和电池节能计划的标题、可访问名称及预览。电池节能计划指固件时段策略，Windows 的节能计划使用系统电源计划名称。

拒绝仅缩小字体、隐藏所有caption、删除预览恢复以及将原理介绍改成另一组常驻提示。
