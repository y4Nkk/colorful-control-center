# Agent Note: 主窗口共用 Tooltip

Status: implemented

## 问题

侧栏直接接入 Radix Tooltip。标题栏、表单、滑杆标记和部分 SVG 的悬停提示由浏览器生成，样式、触发和关闭规则各异。

## 决定

侧栏的 Radix 接入提取为共享 Tooltip，由主窗口入口挂载一次 Provider。提示复用原触发元素，沿用短延迟和指针移出即关闭的规则。浮层挂载在触发器所属的对话框或弹出层内，并等待键盘焦点引起的滚动完成。离页或窗口失焦时关闭当前提示。

主窗口的 HTML `title` 与内联 SVG `<title>` 提示改用共享组件。原有提示文本由标题栏、表单、滑杆和键帽图形各自提供。界面边界检查约束原生提示、Radix 直接接入和 `tooltip` 角色的归属。

## 影响与验证

隔离 Chromium 与模拟 IPC 的聚焦回归覆盖标题栏、折叠导航、连续悬停、键盘自动滚动、禁用选项、滑杆拖动和弹窗内 SVG 提示。Esc 优先关闭弹窗内提示。前端构建、控件规则和 Rust 编译检查通过。

## 备选方案

按模块继续创建提示会产生独立的视觉和交互规则。
